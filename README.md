# Хаос: Эволюция (Fabric, Minecraft 26.3)

Мир, который учится на игроках. Весь контент — на ванильных моделях, без своих ассетов-моделей.

## Что внутри
- **Гнев мира** (ур. 0–10): растёт со временем, смертями, убийствами и боссами.
- **15 мутаций** для обычных монстров (Громила, Титан, Призрак, Вор, Взрывной, Вампир, Ядовитый, Прыгун, Регенератор, Ледяной, Огненный, Грозовой, Щитовой, Роевой, Телепортёр).
- **5 боссов** с 3 фазами, способностями и **адаптацией** (лечатся от того, чем их бьют). Арена запирается барьерной клеткой.
- **3 руды** (Бездны, Кровавая, Грозовая) — из них крафтится **Сигил Хаоса** (ПКМ = призвать следующего босса).
- **События:** метеориты, кровавая луна, чумной туман, орда, грозовой шторм.
- **Общие жизни команды** и счётчик смертей. Жизни кончились — все в наблюдателях.

## Сборка
Нужен JDK 25.
```
./gradlew build
```
Готовый jar: `build/libs/chaosevo-0.1.0.jar`. Положить в `mods/` вместе с Fabric API 0.165.0+26.3.
Мод нужен **и серверу, и всем игрокам**. Руды появляются только в **новых чанках** (создайте новый мир).

## Рецепт Сигила
```
О О О     О = обсидиан
В К Г     В = Осколок Бездны, К = Кровавый кристалл, Г = Грозовое ядро
О О О
```
Первый босс — без ключа. Каждый следующий требует ключ предыдущего (даётся за победу).

## Команды (/chaos ...)
`status`, `reset`, `wrath <N>`, `lives <N>`, `boss <1-5>` (призыв без ключа, для теста), `event <meteor|blood_moon|plague|horde|storm>`
